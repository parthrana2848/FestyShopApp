# Project Instructions for GitHub Copilot

## Prompt History Logging

**IMPORTANT**: This project maintains a prompt history log at `PROMPT_HISTORY.md`.

### Auto-Logging Protocol
- After completing significant tasks or at the end of conversations, append new prompts to PROMPT_HISTORY.md
- Use the format: `## [Date]\n### Session: [id]\n- [prompt]`
- Keep prompts concise (max 300 chars, truncate if needed)
- Group by date and session

### Manual Update
Users can run: `npm run update-prompts` to extract prompts from session logs

## General Guidelines
- Follow existing code patterns in the FeshShopApp project
- Use TypeScript for all new files
- Follow React Native best practices
- Maintain consistency with existing Redux store patterns
